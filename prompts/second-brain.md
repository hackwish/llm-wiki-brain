# Second Brain prompts — CODE + PARA operations

> Skill: `second-brain-ops` · `raw/`, `Clippings/`, `Agent Client/` = Capture, `wiki/` = Organize + Distill,
> `synthesis/` + PARA folders = Express.

## Capture

```
Guardé un artículo que me resonó en Clippings/. Captúralo sin procesar: solo
confirma la fuente y su "why it resonates". No lo ingestes todavía.
```

## Organize with PARA (the three questions)

```
Ayúdame a organizar estos 15 ítems de mi inbox. Aplica las tres preguntas PARA en
orden (proyecto → área → recurso → archivo) y muéstrame a dónde va cada uno antes
de moverlos.
```

## Distill (progressive summarization)

```
Destila la nota wiki/concepts/foco-y-productividad.md en 4 capas: original,
excerpts clave, resumen en bullets, y executive summary de 2-3 frases. Diseñada
para mi yo del futuro: que se lea en segundos.
```

## Express — one Intermediate Packet per session

```
Termina la sesión con un Intermediate Packet: convierte la síntesis de
wiki/synthesis/insights-marketing.md en una comparación reutilizable (tabla + prose)
y fílela en wiki/synthesis/. Luego sugiere 3 posibles usos para ese packet.
```

## Weekly review

```
Haz la revisión semanal del second brain:
1) procesa el inbox en batch, 2) revisa projects/ y actualiza estados,
3) archiva proyectos completados, 4) agrega capas de distillation a notas tocadas,
5) crea un nuevo Intermediate Packet. Actualiza index.md y log.md al final.
```

## Monthly review

```
Haz la revisión mensual: archiva projects terminados o pausados, limpia resources,
revisa la frescura de la wiki (estado/fechas OKF), y sugiere un backup (commit o
sync) del vault.
```
