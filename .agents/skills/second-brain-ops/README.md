# Second Brain Operations Skill

Build and manage a Second Brain using CODE (Capture, Organize, Distill, Express)
and the complete PARA system (Projects, Areas, Resources, Archive), unified with
the LLM Wiki OKF bundle.

## CODE + PARA summary

| Step | Action | Where |
|------|--------|-------|
| Capture | Save what resonates | `raw/`, `Clippings/`, `Agent Client/` (wiki-root ingest sources) |
| Organize | File by actionability (PARA) | `projects/` `areas/` `resources/` `archive/` |
| Distill | Progressive Summarization (4 layers) | `wiki/` pages |
| Express | Intermediate Packets | `wiki/synthesis/`, projects |

## Reviews

- **Weekly**: process inbox, update projects, distill touched notes, one Intermediate Packet.
- **Monthly**: archive completed projects, verify wiki freshness, back up.

See [SKILL.md](./SKILL.md) for the full methodology.
